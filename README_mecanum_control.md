# メカナムホイール4輪ライントレース制御システム

急カーブ対応の角度+位置ハイブリッド制御方式を実装しました。

## 📁 ファイル構成

- **`camera.py`**: カメラ画像受信・線検出・制御データ送信
- **`motor_control.py`**: モータ制御ロジック（メカナムホイール運動学）

## 🚀 使い方

### 1. カメラ側（PC）で実行

```bash
python3 camera.py
```

- ポート5005でカメラ画像を受信
- 線検出を実行し、重心座標と角度を計算
- ポート5006でロボットに制御データを送信
- 2つのウィンドウが表示されます:
  - `line contour only`: 検出結果（赤=輪郭、緑=重心、紫=方向線）
  - `binary (debug)`: 二値化結果

### 2. モータ制御側で実行

```bash
python3 motor_control.py
```

- ポート5006で制御データを受信
- メカナムホイールのモータ速度を計算
- コンソールに制御情報を表示

### 3. ロボットIPアドレスの設定

`camera.py`の8行目を編集:

```python
ROBOT_IP = "192.168.4.1"  # ロボットの実際のIPアドレスに変更
```

## ⚙️ パラメータチューニング

### `motor_control.py`の調整項目

```python
BASE_SPEED = 100    # 基本前進速度（0-255）
Kp_x = 2.0          # 横方向位置補正ゲイン
Kp_angle = 1.5      # 角度補正ゲイン
Kd_x = 0.5          # 横方向微分ゲイン
Kd_angle = 0.3      # 角度微分ゲイン
```

#### チューニング手順

1. **まず`BASE_SPEED`を調整**
   - 低速（50-100）から始める
   - 安定したら徐々に上げる

2. **`Kp_x`（横方向補正）を調整**
   - 小さい値（1.0）から始める
   - 線から外れる場合は増やす
   - 振動する場合は減らす

3. **`Kp_angle`（角度補正）を調整**
   - カーブで曲がりきれない場合は増やす
   - 過剰に回転する場合は減らす

4. **微分ゲイン（`Kd_x`, `Kd_angle`）を調整**
   - 振動を抑えたい場合に増やす
   - 応答が鈍い場合は減らす

### `camera.py`の調整項目

```python
# 二値化パラメータ（42-48行目）
blockSize = 11  # 小さいほど細かい適応（奇数のみ）
C = 2           # 小さいほど敏感

# 面積フィルタ（91行目）
min_area = 100  # ノイズ除外の閾値
```

## 🎮 制御方式の説明

### メカナムホイール運動学

```
        前
    FL ━━━ FR
    │       │
    │   ↑   │  ← ロボット
    │       │
    BL ━━━ BR
        後
```

**制御入力:**
- `vx`: 横移動速度（右が正）
- `vy`: 前進速度（前が正）
- `omega`: 回転速度（反時計回りが正）

**モータ速度計算:**
```
FL = vy - vx - omega
FR = vy + vx + omega
BL = vy + vx - omega
BR = vy - vx + omega
```

### 制御ロジック

1. **位置補正（横移動）**
   - 線の重心が画面中心からずれている → 横移動で補正
   - `correction_x = Kp_x * error_x + Kd_x * d(error_x)/dt`

2. **角度補正（回転）**
   - 線の角度が90度（垂直）からずれている → 回転で補正
   - `correction_angle = Kp_angle * error_angle + Kd_angle * d(error_angle)/dt`

3. **前進**
   - 常に一定速度で前進（`BASE_SPEED`）

## 🔧 トラブルシューティング

### 線検出が不安定
- `camera.py`の二値化パラメータを調整
- 照明条件を改善
- カメラの位置・角度を調整

### ロボットが振動する
- PIDゲインを下げる（特に`Kp_x`, `Kp_angle`）
- 微分ゲイン（`Kd_x`, `Kd_angle`）を上げる

### カーブで曲がりきれない
- `Kp_angle`を上げる
- `BASE_SPEED`を下げる

### 線から外れやすい
- `Kp_x`を上げる
- `min_area`を下げる（より小さな線も検出）

## 📊 デバッグ情報

`motor_control.py`の出力例:
```
X: 85 Y: 60 Ang: 95.3° | ErrX: +5 ErrA: +5.3° | Motors: FL=+98 FR=+110 BL=+110 BR=+98
```

- `X, Y`: 線の重心座標
- `Ang`: 線の角度
- `ErrX`: 画面中心からのX偏差
- `ErrA`: 目標角度(90°)からの角度偏差
- `Motors`: 各モータの速度（-255〜+255）
